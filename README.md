# KOMAD 1.3.3

Build 20261102.3. Paket untuk penggunaan awal tim Pak Eka.

Perbaikan: pemulihan petunjuk Tetap, judul lampiran lengkap dari pembukaan, halaman portrait khusus judul, pembacaan DOC Buleleng hingga baris lampiran tervalidasi, penggantian Pasal I yang khusus mengubah lampiran, daftar BAB bertab, dan penjelasan catatan pemetaan/nomor.

Seluruh sumber pada siklus uji ini dapat dibaca dan membentuk kandidat. Perjalanan Dinas masih mempunyai dua Pasal 3 pada sumber, sehingga perancang harus memastikan nomor sebelum unduhan resmi. Tidak dinyatakan mendukung semua variasi matriks dari seluruh tim. Isi lampiran diisi/digabungkan di Word.

Ekstrak ZIP dan salin isinya ke root repositori. docs harus langsung berada di root, dan docs/.nojekyll disertakan. Ikuti PANDUAN_GITHUB.md. Matriks kantor dan dokumen laporan bukan bagian paket kode publik.

Pengembangan: npm test; python3 scripts/build-pwa.py. Untuk lokal, jalankan BUKA-KOMAD.cmd pada Windows atau python3 buka_komad.py bila Python tersedia.
