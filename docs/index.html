BANTUAN PENGGUNA

Cara menggunakan KOMAD

Ikuti urutan berikut untuk menyusun dan memeriksa draft.

  1. Siapkan matriks Word

    Gunakan file .docx dengan kolom rumusan awal dan hasil penyempurnaan. Kolom keterangan dapat berisi petunjuk yang perlu diperhatikan.

  2. Pilih file matriks

    Klik Pilih File Matriks Word , lalu pilih dokumen dari perangkat. File asli tidak diubah.

  3. Periksa draft dan catatan

    Klik Lihat bagian pada catatan untuk menuju teks yang disorot. Arahkan penunjuk, klik, atau ketuk teks berwarna untuk membaca keterangannya.

    Untuk typo yang jelas, pilih Terapkan rekomendasi atau Biarkan sesuai matriks . Jika urutan pasal, penomoran, atau isi belum pasti, perbaiki matriks lalu pilih Pilih Matriks Revisi .

  4. Simpan dan periksa hasil akhir

    Setelah semua catatan ditangani, lanjutkan ke unduhan Word. Lengkapi nomor, tanggal, nama, atau lampiran yang belum tersedia sesuai keputusan perancang.

Pengaturan ukuran

Tulisan mengatur ukuran teks antarmuka. Zoom draft memperbesar atau memperkecil seluruh halaman pratinjau. Keduanya tidak mengubah format dokumen Word.

AKSES DARI PERANGKAT

Menggunakan KOMAD tanpa internet

Internet diperlukan untuk pemasangan pertama dan mengambil pembaruan aplikasi.

  1. Siapkan saat terhubung internet

    Buka alamat resmi KOMAD. Pilih Pasang aplikasi jika tersedia, lalu ikuti petunjuk browser. Nama menu pemasangan dapat berbeda antarperangkat.

  2. Pastikan aplikasi siap offline

    Tunggu hingga status menunjukkan Siap digunakan offline . Ikon yang sudah muncul belum selalu berarti seluruh berkas aplikasi selesai tersimpan.

  3. Buka melalui ikon KOMAD

    Saat tidak terhubung internet, buka ikon KOMAD di desktop atau layar utama. Pilih matriks yang tersimpan di perangkat, periksa draft, lalu simpan hasilnya.

  4. Ambil pembaruan saat online

    Selesaikan pekerjaan dan simpan draft terlebih dahulu. Sambungkan internet, buka aplikasi, lalu ikuti pemberitahuan pembaruan. Periksa nomor versi dan status kesiapan offline setelah selesai.

Jika aplikasi tidak terbuka saat offline

Sambungkan kembali internet dan periksa kesiapan offline. Jika data situs atau cache browser terhapus, persiapan offline perlu diulang. Simpan juga matriks dan draft di folder perangkat yang mudah ditemukan.
